\# AWS Labs - Le Café Project



\## Description

Ce dépôt contient tous les travaux pratiques réalisés sur AWS/LocalStack pour le projet Le Café.



\## Labs complétés



\### Lab 1 - IAM Foundation

\- Utilisateurs (alice, bob, charlie)

\- Groupes (cafe-developers, cafe-operations)

\- Politiques personnalisées S3 et EC2/CloudWatch

\- Rôle IAM pour application

\- STS (assume-role)



\### Lab 2 - S3 Advanced

\- Buckets avec versioning

\- Site web statique

\- Bucket policies

\- Lifecycle rules



\### Lab 3 - EC2 with IAM Roles

\- Key pairs

\- Security groups

\- Instance profiles

\- User data scripts



\### Lab 4 - SQS \& SNS Pub/Sub

\- Standard et FIFO queues

\- Dead Letter Queue

\- SNS Topic avec subscriptions

\- Filter policies



\### Lab 5 - CloudFormation

\- Infrastructure as Code

\- Template YAML complet

\- Stack deployment



\## Prérequis

\- LocalStack

\- AWS CLI

\- Docker
